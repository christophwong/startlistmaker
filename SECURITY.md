# Security

Start List Maker is a static site. Start lists and athlete data are processed in the browser and are never uploaded, stored on a server or shared.

If you find a security problem, such as a way for a crafted file or project to run script or send data off the page, please report it privately instead of opening a public issue:

- GitHub: **Security → Report a vulnerability** on this repository, or
- email **help@startlistmaker.online**.

Please include the steps to reproduce it and the version shown at the bottom of Help.
